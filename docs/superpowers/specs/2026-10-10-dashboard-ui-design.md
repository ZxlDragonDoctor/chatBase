# 首页运营工作台 UI 设计

日期：2026-10-10

## 目标

重做 ChatBase 首页仪表盘，让用户先看到当天运行情况和核心指标，再查看累计数据、机器人连接状态和常用入口。页面继续使用现有统计 API、机器人 API、权限状态与导航，不改变业务行为。

## 范围

- 只改首页 `DashboardPage.vue` 的页面结构和局部样式。
- 保留 `App.vue` 的侧栏、顶部背景和全站主题，不改其他页面。
- 不新增后端字段、接口、数据库查询或模拟趋势数据。
- 保留当前刷新机制、错误提示、机器人状态语义、所有快捷入口及跳转路由。

## 视觉方向

采用克制的浅色运营工作台：暖白与浅灰背景、深墨色标题、青绿色作为主强调色、琥珀色作为辅助强调色。降低当前粉紫渐变、等权重卡片和大圆角带来的装饰感，使用清楚的数字层级、轻边框和克制阴影。标题和指标优先采用系统可用字体，不依赖新增远程字体或图片资源。

## 页面结构

1. **页头**：左侧显示问候语、用户显示名和当天日期；右侧提供刷新按钮与加载状态。
2. **今日概况**：在页面上方突出今日问答记录、今日 Token 和今日回答成功率。接口返回 0 时照实显示 0；数据不可用时显示 `—`，统计接口失败时保留错误提示。
3. **累计与活跃指标**：用紧凑指标带展示累计问答记录、累计 Token、近 30 日活跃群聊、近 30 日群聊用户、知识库数量和累计回答成功率。数值和标签保持现有后端字段含义。
4. **运营内容区**：桌面端采用主次双栏。主栏展示机器人状态列表及累计 IM 消息、知识库文档、累计平均响应耗时；侧栏展示六个现有快捷入口。小屏改为单栏排列。
5. **状态反馈**：保留加载中、接口错误、空机器人列表、刷新中状态；企微的“回调已配置”继续和“在线”区分显示。

## 数据与交互

- `loadOverview()`、`loadBotList()` 和 30 秒统计刷新行为保持不变。
- 刷新按钮继续同时刷新统计与机器人状态。
- 所有数字继续调用现有格式化函数；成功率没有分母、耗时无有效样本时继续显示“—”。
- 快捷入口的路径、文案及可用性保持不变。
- 保持语义化标题、按钮可键盘操作、状态除颜色外有文字说明，并支持窄屏布局与减少动态效果偏好。

## 验收标准

- 首页展示层级明显区分今日概况、累计与活跃指标、机器人状态、系统运营数据和快捷入口。
- 页面不调用或暗示不存在的趋势数据，不改变统计计算和接口结构。
- 加载、错误、空数据和企微回调状态仍清晰可辨。
- 桌面布局没有横向溢出，窄屏下内容按单栏顺序阅读。
- `npm run build` 成功。
