# ChatBase 全站 UI 重设计规格

日期：2026-10-10

## 目标

为 ChatBase 的登录、问答、运营管理和管理员页面建立一致、易读、适合长时间使用的浅色工作台体验。页面根据任务保留不同布局，但共享一套视觉语言、导航、控件和状态反馈。

## 范围

覆盖当前所有 15 个实际路由页面：

- 登录：`LoginPage.vue`
- 首页与统计：`DashboardPage.vue`、`StatisticsPage.vue`
- IM：`ImGroupsPage.vue`、`ImSingleChatPage.vue`
- 内容与配置：`KnowledgePage.vue`、`AppPage.vue`、`BotManagePage.vue`、`FaqPage.vue`
- 用户入口：`ChatPage.vue`、`FeedbackPage.vue`
- 管理员：`FeedbackManagePage.vue`、`AdminAppsPage.vue`、`AdminKbsPage.vue`、`UserManagePage.vue`

同时更新应用外壳 `App.vue`、全局主题样式 `styles/anime.css` 和直接影响这些页面的共享组件（用户资料、头像裁剪、统计卡、加载与进度组件等）。

保留所有现有 API、数据字段、权限判断、路由、表单校验、聊天/上传/绑定/同步/审批行为。此次工作只调整视觉、信息层级、响应式布局和控件可用性；不新增业务功能、不调整服务端逻辑、不引入新依赖或远程资源。

## 视觉方向

采用浅色运营工作台：暖白与浅灰作为画布和分区底色，深石墨色作为正文，青绿色作为主要操作色，琥珀色用于提醒和次级强调，红色只用于错误与危险操作。移除全屏粉紫光斑、飘落装饰和过度渐变；卡片使用清晰边界、较轻阴影和适中圆角。字体使用系统中文字体栈，不增加远程字体请求。

信息优先级高于装饰：页面标题与主操作明确，指标数字有足够对比度，标签和辅助说明保持可读。动效只用于状态变化和轻量反馈，并遵守减少动态效果偏好。

## 设计系统与应用外壳

- 将现有主题变量收敛成按用途命名的语义变量，统一页面背景、表面、文字、边框、主色、状态色、间距、圆角、阴影和焦点环。
- 全部页面共用一致的标题区、描述、主次按钮、表单控件、筛选工具栏、表格、分页、空状态、加载态、错误提示、标签和弹窗样式。
- 桌面端保留左侧导航信息架构，统一品牌区、导航分组、选中态和底部用户资料操作；窄屏提供可键盘访问的折叠导航。
- 保留管理员导航仅管理员可见、未登录跳转登录和现有路由行为。
- 避免跨页面的全局选择器覆盖业务页面的局部布局；共享设计通过语义变量和可复用类/组件落实。

## 页面布局规则

- **首页**：突出今日概况，再呈现累计/活跃指标、机器人连接状态、系统运营数字和快捷入口；不生成当前 API 不提供的趋势数据。
- **统计**：图表与统计卡使用统一色阶、图例、标题和空数据说明；保留现有图表内容与时间/范围交互。
- **群聊与私聊**：保留列表加详情的工作区结构；工具栏、筛选、消息内容和会话绑定区在窄屏顺序堆叠。
- **知识库、应用、机器人和 FAQ**：统一页面标题、筛选/操作区、卡片或表格、分页及创建/编辑弹窗；危险操作清晰区分。
- **Web 问答**：优先保证消息可读性、会话切换、附件操作和输入区可见；窄屏输入操作不被遮挡。
- **反馈与管理员页**：统一表单校验提示、管理表格、状态标签、详情/回复表单和确认弹窗；保留角色与数据权限行为。
- **登录**：继续单一登录流程和字段，仅重做品牌呈现、表单层级、错误反馈和小屏布局。

## 响应式与可访问性

以宽屏管理工作台为基准，并覆盖平板和手机尺寸。桌面侧栏在窄屏折叠；双栏页面转为单栏；表格在小屏可横向查看或按页面现有数据结构转成易读行卡片，避免整个页面横向溢出。交互控件提供清楚的键盘焦点、可读标签和足够点击区域。错误、成功、在线和配置状态均以文字表达，不只依靠颜色。

## 实施顺序

1. 统一主题变量、全局基础样式、应用导航外壳和共享控件。
2. 迁移首页、统计、IM、知识库、应用、机器人与 FAQ 页面。
3. 迁移登录、Web 问答、反馈及管理员页面和共享弹窗。
4. 对所有路由进行样式冲突与响应式复核，运行前端生产构建。

每一阶段保持页面现有交互和权限逻辑；如果样式调整需要触及业务逻辑，先检查能否通过模板结构和 CSS 完成，避免无关重构。

## 验收标准

- 15 个实际页面在颜色、字体层级、控件、边界、间距和状态表达上保持一致，同时页面布局适配各自任务。
- 登录、会话操作、IM 绑定、机器人管理、知识库同步/上传、FAQ、反馈、管理员功能继续按当前路由、权限和接口工作。
- 桌面侧栏与窄屏导航可用；常见手机宽度下页面无整体横向溢出，表格和输入区仍能操作。
- 加载、空数据、错误、成功、禁用、在线、回调已配置和危险操作状态清晰可辨。
- 不出现伪造的图表或统计数字，不增加外部依赖。
- `npm run build` 成功。
